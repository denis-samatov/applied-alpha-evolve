# Correctness, trust and comparative-experiment acceptance

## Local regression

```bash
PYTHONPATH=open_evolve python -m pytest open_evolve/tests -q
```

All three circle-packing evaluator copies (examples, artifact example and saved-result example)
reject wrong shapes, non-finite coordinates/radii and negative radii before geometric tests.
Zero-radius circles remain permitted. The parent recalculates the sum from feasible radii.
Candidates return bounded numeric JSON, never executable pickle; provider credentials and
PYTHONPATH are not inherited, paths travel as argv, and POSIX process groups are killed after
completion/timeout. stdout/stderr are discarded to avoid unbounded in-memory capture.

This is **trusted local execution**, not a hostile-code sandbox. A candidate still has host-user
filesystem/network rights and may allocate resources. Before generated code from an untrusted
source is run, provision an external no-network, no-secret, read-only-input sandbox with
CPU/memory/disk limits and verify descendant cancellation. No hosted runner was deployed here.
Windows currently kills the direct child only; job-object tree isolation is a hosting prerequisite.
